Configuration

One file, site/config.js, sets up the whole desktop. Every key is optional — what you leave out keeps its default.

The file sets window.DESKTOP_CONFIG. Objects merge key by key with the defaults; lists and plain values replace them. Invalid values are reported in the browser console and replaced by the default — a typo never breaks the desktop.

The most important keys

KeyWhat it does
brand, author, creditThe desktop's name, glyph and logo; the author credit and profile links.
languages, defaultLangThe languages offered (folders in locales/) and the fallback.
siteThe manifest file, your own host names, the home page, the legal pages (legal: ['imprint', 'privacy']), routing rules.
theme, wallpaperMode, accent colours, tile tints, window controls; the wallpapers on offer.
modules, appsWhich optional parts are loaded. Leave one out and it is not even downloaded.
servicesOnline services the site offers: weather, geolocation, fortune, dns. All false by default.
readerHow the content of a page is found: Writing pages.
notifyThe news feed per language and the app that opens its entries.
fortuneThe folder of the sayings (dir), an optional online source (remote: built in or from your own module), local: false for an online-only app, categories to leave out (block) and texts that name the app (texts).

Online services

A service needs two switches: the site offers it (services.fortune: true) and each visitor agrees before the first request. Its host must also be allowed in the connect-src of your Content Security Policy — for example v2.jokeapi.dev for fortune: { remote: 'jokeapi' } or uselessfacts.jsph.pl for remote: 'uselessfacts'. A source your own module adds needs its hosts there as well.

Adding a language

  1. Copy locales/en to locales/<code>, set the name and text direction in _meta.js and translate the files.
  2. Add the code to languages.
  3. Add the language to the texts in site/apps.js, write site/content/<code>/, site/data/fortunes/<code>.json and, if you like, a feed.
  4. Run npm run i18n:check -- <code> and npm run validate.
