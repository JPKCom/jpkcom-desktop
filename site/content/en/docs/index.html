Getting started

Run the desktop on your computer in a minute, then make it your own.

Run it locally

You need Node.js 24 or newer — only for the tools; the desktop itself runs in any current browser.

npm ci
npm run serve

Then open http://localhost:8080/. The desktop needs a web server: opening index.html straight from the disk (file://) does not work, because browsers do not load ES modules from there.

Make it yours

  1. site/config.js — name and brand, languages, which modules and apps are loaded, online services. Every key is documented in the file; see Configuration.
  2. site/apps.js — your apps, collections (bookmarks, showcases), menus and the files the terminal can show. Check it with npm run validate.
  3. site/content/<language>/ — your pages, one folder per language. Writing pages explains the little markup they need.
  4. site/data/ — the sayings of the fortune app (fortunes/<language>.json) and the news feed (feed.<language>.json).

Put it online

Copy the project to your web server — without node_modules, tools and tests. Send the security headers, above all the Content Security Policy; the README has ready-made snippets for common web servers. If you switch on an online service, add its host to connect-src.
