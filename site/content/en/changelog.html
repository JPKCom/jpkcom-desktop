Changelog

What changed in which version of JPKCom Desktop.

1.0.0

The first public release.

  • Window manager with snapping, a tile menu on the zoom button, the window overview and session restore.
  • Menu bar, Dock, desktop icons, “All apps”, context menus, keyboard shortcuts and notification banners.
  • Settings, wallpapers (generated motifs, gradients, colours, pictures), backup and restore, trash.
  • Reader for content pages, image viewer, Catalog for collections, search, calendar with public holidays, weather and news from a JSON Feed.
  • Apps: editor, notes, tasks, calculator, terminal, audio and video player, and the fortune cookie.
  • Any number of languages, a strict Content Security Policy and no build step.
