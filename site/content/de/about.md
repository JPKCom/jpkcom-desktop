# Über JPKCom Desktop

Eine Weboberfläche im Stil eines Desktops — Fenster, Menüleiste, Dock und Apps, direkt im Browser.
Freie Software unter der MIT-Lizenz.

## Was es ist

JPKCom Desktop macht aus einer Website einen kleinen Desktop. Inhaltsseiten öffnen sich in
Fenstern, Lesezeichen und Beispiele liegen in Sammlungen, und eine Handvoll Apps — Editor,
Notizen, Aufgaben, Rechner, Terminal, Medienplayer und ein Glückskeks — speichern ihre Daten
direkt in deinem Browser.

- **Kein Build-Schritt, keine Abhängigkeiten zur Laufzeit.** Native ES-Module.
- **Eine strenge Content Security Policy.** Keine Inline-Skripte oder -Styles, kein `innerHTML`, kein `eval`.
- **Beliebig viele Sprachen.** Jeder Text kommt aus einer Sprachdatei.
- **Barrierearm.** Tastatur überall, Namen für Screenreader, reduzierte Bewegung wird respektiert.
- **Privat von Haus aus.** Online-Dienste fragen vor ihrer ersten Anfrage nach.
