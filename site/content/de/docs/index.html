Erste Schritte

In einer Minute läuft der Desktop auf deinem Rechner — danach machst du ihn zu deinem.

Lokal starten

Du brauchst Node.js ab Version 24 — nur für die Werkzeuge; der Desktop selbst läuft in jedem aktuellen Browser.

npm ci
npm run serve

Dann http://localhost:8080/ öffnen. Der Desktop braucht einen Webserver: index.html direkt von der Festplatte (file://) zu öffnen, klappt nicht, weil Browser von dort keine ES-Module laden.

Zu deinem machen

  1. site/config.js — Name und Marke, Sprachen, welche Module und Apps geladen werden, Online-Dienste. Jeder Schlüssel ist in der Datei beschrieben; siehe Konfiguration.
  2. site/apps.js — deine Apps, Sammlungen (Lesezeichen, Schaufenster), Menüs und die Dateien, die das Terminal anzeigen kann. Prüfen mit npm run validate.
  3. site/content/<Sprache>/ — deine Seiten, ein Ordner pro Sprache. Seiten schreiben erklärt das bisschen Markup, das sie brauchen.
  4. site/data/ — die Sprüche des Glückskekses (fortunes/<Sprache>.json) und der Nachrichten-Feed (feed.<Sprache>.json).

Online stellen

Kopiere das Projekt auf deinen Webserver — ohne node_modules, tools und tests. Sende die Sicherheits-Header, vor allem die Content Security Policy; die README enthält fertige Schnipsel für gängige Webserver. Schaltest du einen Online-Dienst ein, gehört sein Host in connect-src.
