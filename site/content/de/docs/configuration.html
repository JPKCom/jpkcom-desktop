Konfiguration

Eine Datei, site/config.js, richtet den ganzen Desktop ein. Jeder Schlüssel ist optional — was du weglässt, behält seinen Standardwert.

Die Datei setzt window.DESKTOP_CONFIG. Objekte werden Schlüssel für Schlüssel mit den Standardwerten zusammengeführt; Listen und einfache Werte ersetzen sie. Ungültige Werte meldet die Browserkonsole und ersetzt sie durch den Standard — ein Tippfehler legt den Desktop nie lahm.

Die wichtigsten Schlüssel

SchlüsselWofür
brand, author, creditName, Zeichen und Logo des Desktops; Autorenhinweis und Profil-Links.
languages, defaultLangDie angebotenen Sprachen (Ordner in locales/) und die Rückfallsprache.
siteDie Manifest-Datei, eigene Hostnamen, die Startseite, die Rechtstexte (legal: ['imprint', 'privacy']), Routing-Regeln.
theme, wallpaperModus, Akzentfarben, Kachelfarben, Fensterknöpfe; die angebotenen Hintergründe.
modules, appsWelche optionalen Teile geladen werden. Was fehlt, wird gar nicht erst heruntergeladen.
servicesOnline-Dienste, die die Website anbietet: weather, geolocation, fortune, dns. Standardmäßig alle false.
readerWie der Inhalt einer Seite gefunden wird und welche Code-Farben bleiben (keepStyles, styleScope, styleVars): Seiten schreiben.
notifyDer Nachrichten-Feed pro Sprache und die App, die seine Einträge öffnet.
fortuneDer Ordner der Sprüche (dir), eine optionale Online-Quelle (remote: eingebaut oder aus einem eigenen Modul), local: false für eine App nur mit Online-Quelle, Kategorien, die draußen bleiben (block), und Texte, die die App nennen (texts).

Online-Dienste

Ein Dienst braucht zwei Schalter: Die Website bietet ihn an (services.fortune: true), und jede Besucherin, jeder Besucher stimmt vor der ersten Anfrage zu. Sein Host muss außerdem im connect-src deiner Content Security Policy stehen — zum Beispiel v2.jokeapi.dev für fortune: { remote: 'jokeapi' } oder uselessfacts.jsph.pl für remote: 'uselessfacts'. Eine Quelle aus einem eigenen Modul braucht dort ebenfalls ihre Hosts.

Eine Sprache hinzufügen

  1. locales/en nach locales/<Code> kopieren, in _meta.js Namen und Schreibrichtung eintragen und die Dateien übersetzen.
  2. Den Code in languages eintragen.
  3. Die Sprache bei den Texten in site/apps.js ergänzen, site/content/<Code>/ und site/data/fortunes/<Code>.json schreiben, nach Wunsch auch einen Feed.
  4. npm run i18n:check -- <Code> und npm run validate ausführen.
