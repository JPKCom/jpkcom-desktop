Versionshinweise

Was sich in welcher Version von JPKCom Desktop geändert hat.

1.3.0

Feinschliff aus dem Umzug einer echten Website auf den Desktop.

  • Dein eigenes Icon-Set kann jetzt auch die Symbole des Desktops selbst ersetzen — Menüleiste, Fenstersteuerung, Einstellungen, Wetter (iconReplace).
  • Code in Seiten behält im Reader seine Farben, sicher gefiltert, und die Konsole bleibt still.
  • Mitteilungs-Banner zeigen die App, in der ein Artikel öffnet, auf Wunsch mit eigener Bezeichnung (notify.label).
  • Die Startsprache folgt der Reihenfolge der Browsersprachen, und Sprachnamen stimmen in jeder Sprache.
  • Dock und Schreibtischsymbole folgen umbenannten Apps; die privaten Lesezeichen erscheinen unter Einstellungen → Zurücksetzen erst nach dem Entsperren.
  • Jeder Text des Glückskekses, der ihn oder seine Quelle nennt, lässt sich ersetzen, und Updates der Offline-Kopie werden nicht mehr aufgehalten.

1.2.0

Frische Daten, eigene Icons und mehr Wege, eine Website in den Desktop einzubinden.

  • Feeds, Sprüche und alles unter site/data/ und site/content/ werden wieder frisch geladen, auch beim schnellen Start aus der Offline-Kopie — ein neuer Feed-Eintrag bietet keine neue Version mehr an.
  • Eigene Icon-Sets: Icons deiner Website neben den mitgelieferten, auch zweifarbige (iconSets).
  • Handbuchseiten für man im Terminal je Eintrag, Sammlung und Sprache — probier man writing-pages.
  • Web-Fenster merken sich ihre Seite überall auf der Website und können Links auf eine Unterseite teilen; eine Sammlung kann ihre Web-Übersicht in einem eigenen Fenster öffnen.
  • Der Glückskeks lässt sich umbenennen, nur online betreiben und bekommt Online-Quellen aus deinen eigenen Modulen.
  • Eine Website, die vorher einen anderen Service Worker hatte, kann dessen alte Caches entfernen (offline.legacyCaches).

1.1.0

Ein schnellerer Start und mehr für Website-Betreiber.

  • Fenster laden ihren Code erst beim ersten Öffnen: Der Desktop startet mit deutlich weniger Dateien.
  • Der Start fordert alle seine Dateien auf einmal an, und ein wiederholter Besuch startet aus der Offline-Kopie — eine neue Version wird mit einem Neuladen angeboten.
  • Ein Haus-Theme für deine Website (site/theme.css): Rundungen, Glas und Schatten über dokumentierte Tokens.
  • Eigene Apps können ihre Texte neben ihrem Code ablegen; die Beispiel-App „Hallo“ zeigt, wie.
  • Eine Live-Demo, ein Template-Repository und eine Kurzanleitung auf Deutsch und Englisch.

1.0.0

Die erste öffentliche Version.

  • Fensterverwaltung mit Andocken an die Ränder, einem Kachelmenü am Zoom-Knopf, der Fensterübersicht und dem Wiederherstellen der Sitzung.
  • Menüleiste, Dock, Schreibtischsymbole, „Alle Apps“, Kontextmenüs, Tastenkürzel und Mitteilungen.
  • Einstellungen, Hintergründe (erzeugte Motive, Verläufe, Farben, Bilder), Sicherung und Wiederherstellung, Papierkorb.
  • Reader für Inhaltsseiten, Bildbetrachter, Katalog für Sammlungen, Suche, Kalender mit Feiertagen, Wetter und Neuigkeiten aus einem JSON Feed.
  • Apps: Editor, Notizen, Aufgaben, Rechner, Terminal, Audio- und Videoplayer und der Glückskeks.
  • Beliebig viele Sprachen, eine strenge Content Security Policy und kein Build-Schritt.
