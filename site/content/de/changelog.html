Versionshinweise

Was sich in welcher Version von JPKCom Desktop geändert hat.

1.1.0

Ein schnellerer Start und mehr für Website-Betreiber.

  • Fenster laden ihren Code erst beim ersten Öffnen: Der Desktop startet mit deutlich weniger Dateien.
  • Der Start fordert alle seine Dateien auf einmal an, und ein wiederholter Besuch startet aus der Offline-Kopie — eine neue Version wird mit einem Neuladen angeboten.
  • Ein Haus-Theme für deine Website (site/theme.css): Rundungen, Glas und Schatten über dokumentierte Tokens.
  • Eigene Apps können ihre Texte neben ihrem Code ablegen; die Beispiel-App „Hallo“ zeigt, wie.
  • Eine Live-Demo, ein Template-Repository und eine Kurzanleitung auf Deutsch und Englisch.

1.0.0

Die erste öffentliche Version.

  • Fensterverwaltung mit Andocken an die Ränder, einem Kachelmenü am Zoom-Knopf, der Fensterübersicht und dem Wiederherstellen der Sitzung.
  • Menüleiste, Dock, Schreibtischsymbole, „Alle Apps“, Kontextmenüs, Tastenkürzel und Mitteilungen.
  • Einstellungen, Hintergründe (erzeugte Motive, Verläufe, Farben, Bilder), Sicherung und Wiederherstellung, Papierkorb.
  • Reader für Inhaltsseiten, Bildbetrachter, Katalog für Sammlungen, Suche, Kalender mit Feiertagen, Wetter und Neuigkeiten aus einem JSON Feed.
  • Apps: Editor, Notizen, Aufgaben, Rechner, Terminal, Audio- und Videoplayer und der Glückskeks.
  • Beliebig viele Sprachen, eine strenge Content Security Policy und kein Build-Schritt.
